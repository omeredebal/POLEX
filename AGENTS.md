# Polex Trade Architecture Rules

This project uses **Modern Vanilla Web Architecture** (HTML5 + CSS Tokens + Modular ES6 JavaScript) with zero external framework dependencies:
- Clean semantic HTML structure
- CSS design tokens in `assets/css/variables.css`
- Master styling in `assets/css/main.css`
- Modular JS in `assets/js/main.js` and bilingual dictionary in `assets/js/i18n.js`
- Local dev server via `npm run dev`
