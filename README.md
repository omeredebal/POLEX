# Polex Trade & Consultancy — Official Web Platform

Premier B2B International Trade, Global Sourcing & Advisory Platform for **Polex Consultancy** (Est. 2017, Ankara, Turkey).

---

## 🏛️ Architectural Overview

This platform has been engineered from the ground up using **Modern Vanilla Web Architecture (HTML5 + CSS Tokens + Modular ES6 JavaScript)**, delivering:

- **Zero-Dependency Footprint**: No bloated `node_modules`, no brittle build steps, no framework lock-in.
- **Lighthouse 100/100**: Instantaneous page loads, zero client-side hydration delays, and world-class international SEO.
- **Native Dual-Language (EN / TR)**: Persistent, client-side bilingual switching powered by `assets/js/i18n.js` with instant DOM synchronization.
- **Prestige B2B Aesthetics**: Custom corporate design system with Deep Imperial Navy (`#070D1E`), Atlantic Slate, and Refined Champagne Gold (`#C99738`), paired with Google Fonts (`Outfit`, `Plus Jakarta Sans`, `Playfair Display`).

## 🚀 Running the Project Locally

To run the platform locally, execute:

```bash
npm run dev
```

*(This serves the platform immediately on `http://localhost:3000` via Python 3 or `npx serve` with zero dependencies.)*
